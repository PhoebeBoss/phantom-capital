# Phoebe v2 - AI Agent with Groq

Autonomous AI agent running on open-source Groq LLM (Llama 3.3 70B).

## Features
- Groq LLM integration (free tier)
- Telegram bot interface
- Memory persistence
- Health check endpoint
- Zero Anthropic dependency

## Environment Variables
```
GROQ_API_KEY=gsk_...
TELEGRAM_BOT_TOKEN=...
```
